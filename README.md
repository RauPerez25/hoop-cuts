# Hoop Cuts

Instalador de **Hoop Cuts**, la app para cortar y revisar vídeos de partidos de baloncesto.

- Descarga: [Instalar-Hoop-Cuts.exe](https://github.com/RauPerez25/hoop-cuts/releases/latest/download/Instalar-Hoop-Cuts.exe) (Windows 10/11)
- Necesitas una **clave de licencia**. Al abrir la app por primera vez te la pide y descarga el programa.

Este repositorio solo contiene el instalador.
